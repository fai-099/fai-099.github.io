## Website maintenance

This repository also hosts the website at **https://fai-099.github.io/fai-099/**.

- GitHub Pages: publish `main` from `/(root)`.
- Homepage: `index.html`.
- Profile links: `assets/profile.js`. Google Scholar can be added here when ready.
- Publications: `assets/app.js`.
- CV and portrait: `docs/`.
- Setup and update guide: [GITHUB_SETUP.md](GITHUB_SETUP.md).

The website uses plain HTML, CSS, and JavaScript with local fonts and images. No package installation or custom build workflow is required to publish it. To preview locally with Python, run `python3 scripts/serve.py`; `python3 scripts/build.py` creates a portable copy in `dist/`.
